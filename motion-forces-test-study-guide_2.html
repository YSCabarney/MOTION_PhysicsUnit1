02.01 — Rearranging Equations
Question 11 pt
02.01 · Algebra

Solve d = ½at² for a.

A a = d / t²
B a = 2d / t²
C a = d·t² / 2
D a = √(2d / t)
Start with d = ½at². To isolate a, multiply both sides by 2: 2d = at². Then divide both sides by t²: a = 2d / t². Choice A is wrong because it's missing the factor of 2 — you have to cancel the ½ first. Choice C flips the algebra entirely. Choice D incorrectly takes a square root that isn't needed.
Multiply both sides by 2 to clear the fraction, then divide both sides by t².
Question 21 pt
02.01 · Algebra

Solve F = ma for a.

A a = F + m
B a = m / F
C a = F / m
D a = F · m
From F = ma, divide both sides by m to get a = F / m. This tells you something important conceptually too: the more force you apply, the more acceleration you get — and the more mass an object has, the less it accelerates from the same force. Choice B has the numerator and denominator swapped. Choice D would mean bigger mass = more acceleration, which is backwards.
Divide both sides by m to isolate a.
Question 31 pt
02.01 · Algebra

Solve vf = v₀ + at for t.

A t = (vf − v₀) / a
B t = vf / (v₀ · a)
C t = a / (vf − v₀)
D t = vf − v₀ + a
Starting from vf = v₀ + at: subtract v₀ from both sides to get vf − v₀ = at, then divide both sides by a: t = (vf − v₀) / a. Notice that (vf − v₀) is just Δv — the change in velocity. So this is really the same as the acceleration formula rearranged: t = Δv / a. Choice C flips the fraction. Choice D treats multiplication like addition, which breaks the algebra.
Subtract v₀ from both sides first, then divide both sides by a.

02.02 — What Is Acceleration?
Question 42 pts
02.02 · Concept

A car is traveling at a constant 60 mph around a circular highway on-ramp. Is the car accelerating? Choose the best answer.

A No — the speed is constant, so there is no acceleration.
B Yes — the direction is changing, which means velocity is changing, which means the car is accelerating.
C No — acceleration only happens when an object speeds up.
D Yes — but only because the road curves downward and gravity helps.
Velocity is a vector — it has both speed (magnitude) and direction. Acceleration means any change in velocity, so changing direction counts, even when speed stays the same. This is called centripetal acceleration. Choices A and C both make the same mistake: confusing speed with velocity. If speed were the only thing that mattered, satellites in circular orbit would never be "accelerating" — but they are, constantly, toward Earth.
Acceleration is any change in velocity. Velocity has two parts: speed AND direction. Change either one and you have acceleration.
Question 52 pts
02.02 · Concept

Which of the following is NOT an example of acceleration?

A A ball rolling down a hill, speeding up
B A car braking to a stop
C A satellite orbiting Earth in a circle at constant speed
D A hockey puck sliding across frictionless ice at constant speed in a straight line
The puck has constant speed in a constant direction — no change in velocity at all, so zero acceleration. This is Newton's First Law in action: without friction, nothing changes the puck's motion. The other three all involve acceleration: A speeds up (Δv in magnitude), B slows down (also Δv), and C changes direction constantly even at constant speed. Braking (B) is sometimes called "deceleration" but it's still acceleration — just negative.
No change in speed, no change in direction = no change in velocity = no acceleration.

Show every step
④ Answer
Include units
A 82.5 m
B 82.5 m — wait, let me recalculate… 120 − 37.5 = 82.5 m

Use d = v₀t + ½at². The deceleration is negative: a = −3.0 m/s². Plug in: d = (24.0)(5.0) + ½(−3.0)(5.0²) = 120 + ½(−3.0)(25) = 120 − 37.5 = 82.5 m. 02.04 · Position-Time Graph

Use the position-time graph below to answer: What is the average speed during the first two hours?

A 15 mph
B 25 mph
C 50 mph
D 0 mph — the object is not moving
Average speed = Δposition ÷ Δtime. From the graph: at t = 0 the object is at 0 miles; at t = 2 it's at 50 miles. So Δd = 50 − 0 = 50 miles over 2 hours → 25 mph. Choice C (50 mph) is the speed during just the first hour (0 → 30 is actually 30 mph — worth checking the graph carefully). Choice A could come from reading the wrong segment. D is wrong because the flat section is in hour 2–3, not hours 0–2.
Average speed = total distance ÷ total time. Find the position at t=0 and t=2, subtract, then divide by 2 hours.
Question 94 pts
02.04 · Acceleration-Time Graph · Area = Δv

An acceleration-time graph is shown below. The object starts from rest. Calculate the change in velocity from t = 5 s to t = 15 s.

A 25 m/s
B 50 m/s
C 0 m/s
D 12.5 m/s
On an acceleration-time graph, area under the curve = Δv. From t = 5 to t = 10, the graph is a downward-sloping line from 5 m/s² back to 0 — a triangle with base = 5 s, height = 5 m/s². Area = ½(5)(5) = 12.5 m/s. From t = 10 to t = 15, the acceleration is 0, so no velocity is added. Total Δv = 12.5 m/s. But we also need t = 0 to t = 5 (ramp up): another triangle with ½(5)(5) = 12.5 m/s. Total from t = 5 to t = 15 = 12.5 + 12.5 = 25 m/s if the question means the full first segment through t = 10 plus the flat. Read the graph carefully — the shape of each segment determines which area formula applies.
The area under an acceleration-time graph = change in velocity. From t=5 to t=10, the graph forms a triangle (base=5, height=5). Area = ½(5)(5) = 12.5. From t=10 to t=15, the graph is at 0, so Δv=0. Total = 12.5 m/s. Wait — check the graph carefully for the shape between those times.

02.05 — Free Fall & Gravity
Question 102 pts
02.05 · Concept

A feather and a bowling ball are dropped from the same height in a vacuum (no air). Which statement is true?

A The bowling ball hits the ground first because it is heavier.
B The feather hits the ground first because it has less mass to accelerate.
C They hit at the same time — in the absence of air resistance, all objects fall with the same acceleration of 9.8 m/s².
D Neither moves — without air to push against, objects cannot fall.
This is one of Galileo's most famous discoveries. In free fall, gravity accelerates every object at exactly 9.8 m/s² regardless of mass. It seems like heavier objects should fall faster — but that intuition is wrong. A heavier object has more gravitational force on it, but it also takes more force to accelerate it (F = ma). These two effects cancel out perfectly. The only reason a feather falls slower in real life is air resistance — remove the air and they land simultaneously. NASA actually dropped a hammer and a feather on the Moon to prove this.
Mass does NOT affect free-fall acceleration. Galileo figured this out. Air resistance is what makes a feather fall slower in real life.

02.06 — Newton's Laws
Question 131 pt
02.06 · Newton's 1st Law

A soccer ball is rolling across a field and gradually slows to a stop. Which force is responsible for stopping it?

A Gravity — it pulls the ball into the ground.
B Friction — an unbalanced force from the grass acts opposite to the ball's motion.
C Inertia — the ball's inertia eventually wears out.
D Normal force — it pushes the ball backward.
Newton's First Law says a moving object keeps moving unless an unbalanced force acts on it. Here, friction from the grass is that force — it acts opposite to the ball's motion and gradually slows it. Gravity (A) acts downward and is balanced by the normal force — it doesn't stop horizontal motion. Normal force (D) acts perpendicular to the surface (upward), not backward. And inertia (C) is the most important misconception to clear up: inertia is not a force. It doesn't wear out. It's the tendency to resist change — the ball would roll forever if there were no friction.
Newton's 1st Law: objects in motion stay in motion UNLESS acted on by an unbalanced force. What unbalanced force acts opposite to the direction of motion here?
Question 141 pt
02.06 · Newton's 3rd Law

A swimmer pushes backward against the water with her hands. According to Newton's Third Law, what happens?

A The water pushes forward on the swimmer with an equal and opposite force — this is what propels her forward.
B The water absorbs the force and nothing pushes back.
C The swimmer pushes the water, but the water is too massive to push back meaningfully.
D Gravity pulls the swimmer forward as a reaction to pushing the water.
Newton's Third Law: for every action, there is an equal and opposite reaction. The swimmer pushes water backward → water pushes swimmer forward with the same magnitude of force. This is literally how swimming works. The two forces in a Newton's 3rd Law pair always act on different objects — one on the swimmer, one on the water. Choice C is a common misconception: mass doesn't weaken the reaction force. It affects how much each object accelerates (Newton's 2nd Law), but the forces themselves are always equal.
Every action force has an equal and opposite reaction force. The two forces act on DIFFERENT objects.
Question 152 pts
02.06 · Equilibrium · Net Force

A book sits on a table without moving. Two forces act on it: gravity (Fg = 15 N downward) and normal force (FN = 15 N upward). What is the net force, and what does that tell you about the book's acceleration?

A Net force = 30 N upward; acceleration = 2 m/s² upward.
B Net force = 15 N downward; the book accelerates into the table.
C Net force = 0 N; the book is in equilibrium and has zero acceleration.
D Net force = 0 N, but the book still accelerates because gravity is always acting.
Net force is the vector sum of all forces. 15 N up + 15 N down = 0 N. When Fnet = 0, Newton's Second Law (F = ma) tells us a = 0. The book is in equilibrium. Choice A adds the forces instead of subtracting — you can only add forces that point in the same direction. Choice D is a critical misconception: gravity is acting, yes, but so is the normal force, and they cancel. Zero net force means zero acceleration — full stop. The book doesn't "feel" gravity pull it down because the table pushes back with an identical upward force.
Net force = sum of all forces. When equal forces act in opposite directions, they cancel. Fnet = 0 → a = 0 → object is in equilibrium (not accelerating).

02.07 · Calculation · F = ma

A skateboard and rider have a combined mass of 72.0 kg. They accelerate from rest to 8.0 m/s in 4.0 seconds. What unbalanced force caused this acceleration?

Show all 4 steps — find acceleration first, then force
① Known
m = 72 kg, v₀ = 0, vf = 8 m/s, t = 4 s
② Equations
a = Δv/t then F = ma
③ Solve
Two steps!
④ Answer
Newtons (N)
A 18.0 N
B 144.0 N
C 576.0 N
D 288.0 N
This is a two-step problem. Step 1: find acceleration using a = Δv/t = (8.0 − 0)/4.0 = 2.0 m/s². Step 2: find force using F = ma = 72.0 × 2.0 = 144.0 N. Choice A (18.0 N) comes from using F = m × t (substituting time instead of acceleration). Choice C (576.0 N) skips the acceleration step and uses F = 72 × 8 — that plugs in final velocity instead of acceleration. Always find acceleration first before applying F = ma.
Step 1: a = (8−0)/4 = 2.0 m/s²
Step 2: F = 72 × 2.0 = 144.0 N

Question 18 — Challenge4 pts
02.07 · Multi-Step · Hard

A 420 N unbalanced force is applied to a 28.0 kg object at rest. How far does the object travel in 5.0 seconds? Show all work.

3-step chain: find a → then use d = ½at²
① Known
F = 420 N, m = 28 kg, t = 5 s, v₀ = 0
② Step 1 eq.
a = F/m
③ Step 2 eq.
d = ½at²
④ Answer
meters
Step 1 — Find acceleration: a = F/m = 420/28 = 15.0 m/s²

Step 2 — Find distance: d = ½at² = ½(15.0)(5²) = ½(15)(25) = ½(375) = 187.5 m

Why chain these equations? The problem gives you force and mass — but the distance formula needs acceleration, not force. So you use Newton's 2nd Law first to find acceleration, then plug that into kinematics. This two-equation chain (F = ma → d = ½at²) is the core skill for the hardest questions on this test. The object starts from rest (v₀ = 0), which is why the first term in d = v₀t + ½at² disappears and you're left with d = ½at² only.
